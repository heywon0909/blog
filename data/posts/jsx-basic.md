## JSX란

JSX란 JavaScript Syntax Extension으로 자바스크립트 확장 문법이다.
html과 유사하지만, html과 약간의 차이가 존재한다.

1. 카멜 케이스
   JSX 속성은 html 과 달라 카멜케이스로 작성된다.
   html에서의 onclick이 JSX에서는 첫문자를 대문자로 작성합니다.
2. 자바스크립트 표현식 사용 가능
   엘리먼트 트리 내부에서 코드 실행이 가능하다.
   즉, 자바스크립트 표현식을 사용이 가능하다는 것이다. 표현식이란 값을 만들어 내는 계산 식으로 쉽게 말하면 삼항연산자, 문자열 치환등을 의미한다.

## 브라우저는 어떻게 JSX를 이해할까

JSX를 브라우저에서 이해하기 위해서는 브라우저가 이해할 수 있게 변환하는 ‘빌드 단계' 가 필요하다. 코드가 빌드를 거쳐 JS로 변환되어 최종 배포용 번들에 포함되는데 이 과정을 Transpile 이라고 한다.
JSX는 babel이라는 JavaScript complier를 통해 JSX를 Transpile한다.

## JSX의 컴파일

JSX는 babel에 의해 컴파일되는데 그 과정을 살펴보면,

1. JSX 프라그마(열린태그)를 만나
2. 변수 이름, 객체 키, 값 등 의미있는 토큰으로 분해한 후
3. 토큰을 가져와 AST 로 변환
4. AST를 JavaScript 번들로 생성

이 과정을 거친다.
