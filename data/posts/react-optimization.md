## React의 지연로딩

애플리케이션의 규모가 커지면 자바스크립트 코드의 양이 증가한다. 엄청난 양의 자바스크립트 번들을 다운로드하면 사용자의 초기 로딩에 영향을 미칠 수 있다.
이를 방지하기 위해 코드를 분할하여 초기 로딩이 아닌 특정 페이지, 기능에 진입시 필요한 자바스크립트만 읽어 들이는 방법이다.

## React의 동시성 렌더링

이전 동기식렌더링은 메인 스레드를 가로막아 사용자의 경험이 저하되는 문제가 있었다. 예를 들면 UI반응이 느려지거나 응답하지 않아 사용자가 불편을 겪는 상황이 있다.
이러한 문제를 완화하는 방법으로 여러 업데이트를 일괄 처리해서 메인 스레드에서 수행되는 작업을 최소화하였지만, 동기식 렌더링은 모든 업데이트를 동일하게 취급하는 문제가 발생했다.

이는 사용자에게 보이는 업데이트와 사용자에게 보이지 않는 업데이트를 동일하게 취급하여 사용자의 경험이 저하되는 문제가 있었다.

사용자의 경험 향상을 위해 사용자가 볼 수 있고, 상호작용 할 수 있는 항목이 우선적으로 업데이트 되어야한다.

이를 위해 리액트는 동시성 렌더링을 사용해 업데이트와 우선순위를 매겨, 중요한 업데이트가 덜 중요한 업데이트에 가로막히지 않게 하였다.

## React의 동시성 렌더링 흐름

리액트의 동시성 렌더링 흐름을 살펴보면 텍스트 입력과 같은 사용자의 상호작용 또는 setState를 통해 리액트가 업데이트가 필요하다고 인지하면, 렌더레인을 통해 어떤 작업이 더 급한지 판단하여 우선순위를 결정한다.
이후 스케쥴러가 각 작업에 대한 실행 시간을 판단하고 시간을 예약한다.
fiber reconciler 라는 리액트 엔진을 통해 새로운 fiber tree를 생성한다.
fiber reconciler는 우선순위가 낮거나 오래 걸리는 작업을 중단하고 나중에 다시 실행할 수 있다.
이후 실제 DOM에 업데이트를 진행한다.

## 동시성 렌더링 API

개발자가 useTransition, useDefferedValue 와 같은 API를 사용해 업데이트의 우선순위를 재조정하여 애플리케이션의 성능과 응답성을 조절할 수 있다.

useTransition 훅은 우선순위가 높은 업데이트로 인해 UI가 응답하지 않는 것을 방지하는 리액트 훅이다.. 탭을 눌러 데이터를 호출하는 화면에서 한 탭을 클릭했으나 데이터 불러오는 속도가 느려, 탭이 제대로 눌린건지 사용자가 확인이 어려운 경우를 예로 들 수 있다. useTransition은 isPending, startTransition을 반환합니다. isPending은 transition 이 진행중인지 여부를 나타낸다. startTransition은 지연되거나 낮은 우선순위가 부여되어야하는 업데이트를 감싸는 함수로 우선순위를 낮출 수 있다.

useDefferedValue는 특정 UI 업데이트를 미뤄 애플리케션의 과부하를 처리할 수 있다. 이 말의 진짜의미는 검색을 통해 데이터를 불러오는 화면에서 text 입력으로만 검색되는 상황에서 text 변화에 따른 데이터를 불러오는 부분이 text 입력과의 지연이 발생할때 text를 useDefferedValue로 감싸서 이전 값을 더 유지하여 UI 과부하를 처리하겠다는 것이다.
useDefferedValue로 감싸진 값은 업데이트에서는 오래된 값을 오래 유지하고, 새 값으로 업데이트할 시점을 제어해 부드러운 사용자 경험을 유지할 수 있다.
